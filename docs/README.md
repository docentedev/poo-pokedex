# Guías para estudiantes

Material de apoyo del proyecto **Pokédex de Cartas** (JavaFX + POO).

| Guía | Contenido |
|---|---|
| [Guía paso a paso (GUIA.md)](GUIA.md) | Construcción completa del proyecto desde cero: modelo, DAO, repository, controlador, FXML y todo el código. |
| [Campos calculados en una `TableView`](campos-calculados-en-tableview.md) | Cómo mostrar valores calculados en columnas, tipos de columna, `cellFactory`, errores comunes y ejercicio. |
| [`ComboBox` y `CheckBox`](combobox-y-checkbox.md) | Listas desplegables, casillas de selección, listeners, habilitación dinámica de campos y su uso en el formulario. |

## Orden sugerido

1. **GUIA.md**: construye el proyecto completo siguiendo los pasos.
2. **TableView**: profundiza en cómo se muestran los datos (incluye el valor calculado de cada carta).
3. **ComboBox y CheckBox**: profundiza en cómo el usuario elige los datos que se van a registrar.
